Video Mode

Агент смотрит на экран

Непрерывный захват + MiniMax-M3 vision. Экономия токенов через SAD-diff детектор. Подсказки в реальном времени.

🎮

Как это работает

Агент снимает выбранный монитор через xcap и отправляет кадры в MiniMax-M3. SAD-diff детектор (64×36 grayscale) вызывает LLM только при заметных изменениях — это экономит токены и снижает задержку.

1. xcap capture → resize → JPEG ≤1280px 2. SAD diff → 64×36 grayscale comparison skip (до 10s) ← no change detected 3. changed? → MiniMax-M3 vision call 4. agent-hint → Svelte log + TTS budget: 100 calls/session, then LLM off
Win / macOS / Linux X11 Wayland не поддерживается privacy: only RAM

Творческий партнёр. Генерирует идеи, предлагает нестандартные решения. Для брейншторма и прототипирования.

Raziel

Research companion

Исследователь. Читает, анализирует, суммирует. Помогает разобраться в новой теме быстро и глубоко.

Архитектура

Стек технологий

Tauri 2 как desktop shell, Svelte 4 как UI, Rust как backend. LanceDB, bge-small, xcap.

UI Layer — Svelte 4 + TypeScript + Vite
Desktop Shell — Tauri 2 (Rust)
AI Providers — Anthropic / MiniMax / OpenAI
Vector Store — LanceDB (embedded)
Embeddings — bge-small-en-v1.5
Screen Capture — xcap 0.9 (Win/macOS/Linux X11)
Vision — MiniMax-M3 (screen understanding)
Storage — keyring (API keys), localStorage (preferences)
Credentials — Windows Credential Manager / macOS Keychain / Linux Secret Service
Установка

Быстрый старт

Соберите из исходников за пять минут. Windows, macOS, Linux.

1

Установите зависимости

Rust (stable 1.78+), Node.js 18+. Для screen capture на Linux нужен X11.

# Rust curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh # Node.js — https://nodejs.org
2

Клонируйте и соберите

Dev-сборка с hot reload для отладки, или production для релиза.

git clone https://github.com/roman-vmb/luna-agent-tauri cd luna-agent-tauri npm install npm run tauri:dev # dev-режим # или npm run tauri:build # production
3

Настройте API-ключи

Ключи хранятся в системном keyring. Для Video Mode дополнительно нужен MINIMAX_API_KEY.

# PowerShell $env:MINIMAX_API_KEY = "your-key-here" npm run tauri:dev
